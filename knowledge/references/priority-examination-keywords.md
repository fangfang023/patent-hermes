# 《关键数字技术专利分类体系（2023）》摘要与关键词

## 1. 文件来源

国家知识产权局于2023年发布《关键数字技术专利分类体系》，用于指导重点领域的专利审查、统计和优先审查。该分类体系覆盖人工智能、集成电路、电子通信等关键数字技术领域。

---

## 2. 分类体系结构

### 2.1 一级分类

| 编号 | 一级分类 | 说明 |
|------|---------|------|
| 1 | 人工智能 | 涵盖机器学习、自然语言处理、计算机视觉、知识图谱等 |
| 2 | 集成电路 | 涵盖芯片设计、制造工艺、封装测试等 |
| 3 | 电子通信 | 涵盖移动通信、光通信、卫星通信等 |
| 4 | 量子信息 | 涵盖量子计算、量子通信、量子测量等 |
| 5 | 新能源汽车 | 涵盖电池技术、电驱系统、智能网联等 |
| 6 | 其他数字技术 | 物联网、区块链、大数据等 |

### 2.2 人工智能二级分类（重点关注）

| 编号 | 二级分类 | 关键技术方向 |
|------|---------|------------|
| 1.1 | 机器学习 | 监督学习、无监督学习、强化学习、迁移学习、联邦学习 |
| 1.2 | 深度学习 | 卷积神经网络、循环神经网络、Transformer、注意力机制 |
| 1.3 | 自然语言处理 | 分词、语义理解、文本生成、机器翻译、对话系统 |
| 1.4 | 计算机视觉 | 图像识别、目标检测、图像分割、视频分析 |
| 1.5 | 知识图谱 | 知识抽取、知识推理、知识表示 |
| 1.6 | 语音技术 | 语音识别、语音合成、声纹识别 |
| 1.7 | 智能决策 | 规划与调度、推荐系统、智能控制 |
| 1.8 | AI基础设施 | 训练框架、推理引擎、模型压缩、边缘计算AI |
| 1.9 | AI安全与隐私 | 对抗防御、隐私保护、可解释AI、公平性 |
| 1.10 | AI应用 | 智能制造、智慧医疗、智能交通、智能教育、智能金融 |

## 3. 匹配方法

### 3.1 匹配步骤

```
步骤1：提取专利申请的核心技术关键词
  → 从权利要求书和说明书中提取技术术语

步骤2：与分类体系关键词逐一比对
  → 按一级→二级→关键技术方向逐层匹配

步骤3：确定最匹配的分类号
  → 选择覆盖面最广且最精确的分类

步骤4：输出匹配结果
  → 分类编号 + 分类名称 + 匹配的关键词 + 匹配理由
```

### 3.2 匹配规则

- 一个专利申请可以匹配多个分类号
- 优先匹配最具体的二级分类
- 当无法精确匹配二级分类时，匹配一级分类
- 匹配时应同时考虑技术方案和应用场景

## 5. 优先审查申请条件

根据《专利优先审查管理办法》：

- 涉及节能环保、新一代信息技术、生物、高端装备制造、新能源、新材料、新能源汽车、智能制造等国家重点发展产业
- 各省级知识产权局重点支持的产业领域
- 申请人有实施准备的（已开始实施或有明确实施计划）
- 其他对国家利益或公共利益具有重大意义需要优先审查的

符合《关键数字技术专利分类体系》的专利申请通常可以申请优先审查。
