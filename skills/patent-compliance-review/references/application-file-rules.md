# 申请文件、附图、摘要和形式性规则

来源基础：指南2023第一部分第一章第4.2-4.5节、第一部分第二章第7.2-7.5节、第五部分第一章第3节和第5节；修改2026涉及发明人、序列表费用等程序性更新，仅在全文检查时提示。

## 1. 文件构成

- 发明专利申请应有说明书，必要时有附图，以及摘要和权利要求书。
- 实用新型专利申请应有说明书、说明书附图、摘要和权利要求书。
- 说明书、权利要求书和摘要文字应整齐清晰，不得涂改或行间加字。
- 一页纸上不得包含两种以上文件，例如不得同页既有说明书又有权利要求书。
- 请求书、权利要求书、说明书、摘要、附图中文字部分等应打字或印刷。
- 申请文件应使用中文；外文科技术语没有统一中文译名的，可注明原文。

## 2. 说明书形式

- 说明书首页第一行应写发明或实用新型名称，且与请求书一致。
- 名称与正文之间应空一行，不应写"发明名称"或"名称"等字样。
- 说明书应包括技术领域、背景技术、发明/实用新型内容、附图说明、具体实施方式等部分，并在每一部分前写标题。
- 无附图时，说明书文字部分不包括附图说明及其标题。
- 说明书文字部分可以有化学式、数学式或表格，但不得有插图。
- 涉及核苷酸或氨基酸序列且符合规定长度要求的，应将序列表作为说明书单独部分提交。
- 说明书应以阿拉伯数字顺序编写页码。

## 3. 说明书附图

- 附图是说明书组成部分，用图形补充文字描述，使技术特征和整体技术方案可理解。
- 附图应清楚反映发明或实用新型内容。
- 附图应使用包括计算机在内的制图工具绘制，线条均匀清晰，不得涂改。
- 附图一般用黑色墨水；必要时可提交彩色附图以清楚描述技术内容。
- 剖面线不得妨碍附图标记线和主线条清楚识别。
- 几幅附图可绘制在一张图纸上；一幅总体图可另有局部放大图。
- 附图周围不得有与图无关的框线。
- 多幅附图应使用阿拉伯数字编号，如图1、图2，并标注在相应附图正下方。
- 附图应尽量竖向绘制并彼此明显分开；必须水平布置时按指南方向要求处理。
- 附图标记应使用阿拉伯数字编号。
- 说明书文字未提及的附图标记不得在附图中出现，附图未出现的标记不得在说明书中提及；同一组成部分附图标记应一致。
- 附图大小和清晰度应保证缩小到三分之二时仍能清楚分辨细节。
- 同一附图一般采用相同比例；为清楚显示可增加局部放大图。
- 附图中除必要词语外不得含其他注释；词语应使用中文，必要时括注原文。
- 流程图、框图应作为附图，并在框内给出必要文字和符号。
- 一般不得使用照片作为附图；实用新型附图不得使用工程蓝图、照片。
- 实用新型说明书附图中应有表示要求保护产品形状、构造或其结合的附图，不得仅有现有技术附图，也不得仅有表示效果、性能的图。
- 附图应以阿拉伯数字顺序编写页码。

## 4. 权利要求书形式

- 多项权利要求应使用阿拉伯数字顺序编号。
- 权利要求书不得加标题。
- 权利要求书应以阿拉伯数字顺序编写页码。
- 权利要求中的附图标记应与说明书附图标记一致。
- 权利要求不得用图形表达技术特征，通常也不得使用表格。

## 5. 摘要

- 摘要应写明名称和所属技术领域，清楚反映要解决的技术问题、解决该问题的技术方案要点以及主要用途。
- 摘要不得写成宣传性文本，也不用于解释保护范围。
- 摘要文字部分不得使用标题。
- 摘要文字部分包括标点符号不得超过300字。
- 摘要可以包含最能说明发明的化学式；该化学式可视为摘要附图。
- 说明书有附图的，申请人应指定一幅最能说明技术方案主要技术特征的附图作为摘要附图，并在请求书中写明图号。
- 摘要附图必须是说明书附图之一，且应能说明主要技术特征。
- 摘要附图大小和清晰度应保证缩小到4厘米乘6厘米时仍能分辨细节。
- 实用新型摘要通常应有摘要附图，并从说明书附图中选出能反映技术方案的附图。

## 6. 实用新型初步审查相关撰写规则

- 实用新型说明书应对实用新型作出清楚、完整说明，以本领域技术人员能够实现为准。
- 实用新型说明书应包括技术领域、背景技术、实用新型内容、附图说明和具体实施方式。
- 实用新型内容应描述要解决的技术问题、技术方案和有益效果。
- 实用新型内容应与权利要求限定的技术方案相适应。
- 实用新型具体实施方式至少给出一个实现该实用新型的优选方式，并应对照附图说明。
- 实用新型附图必须能反映要求保护产品的形状、构造或者其结合。
- 实用新型权利要求应以说明书为依据，清楚、简要地限定保护范围。

## 7. 修改和新增内容风险

仅在检查修改文本或进行版本对比时使用本节。

- 修改不得超出原说明书和权利要求书记载范围。
- 超范围判断以本领域技术人员能否从原说明书和权利要求书直接地、毫无疑义地确定为准。
- 在说明书补入原权利要求书记载而原说明书没有描述的内容，一般不视为超范围；但仍需满足支持和充分公开。
- 补入原说明书和权利要求书均未记载、且不能由原附图直接且毫无疑义确定的技术特征，属于超范围风险。
- 明显错误更正不视为超范围，但正确内容必须能从上下文清楚判断且没有其他解释。
- 附图中明显可见且有唯一解释的结构，允许补入说明书并写入权利要求。
