## 审查意见通知书结构

一份标准的中国专利审查意见通知书包含以下内容：

```
申请号：XXXXXXXXXXXX.X
申请人：XXX
发明名称：XXX

审查意见：
1. 权利要求X不具备新颖性（对比文件：CNXXXXXXA）
   [审查员具体论述]

2. 权利要求X不具备创造性（对比文件：CNXXXXXXA + CNYYYYYYA）
   [审查员具体论述]

...
```

## 审查意见类型分类

### 一、新颖性缺陷（专利法第22条第2款）

**审查员论述模式**：
> "权利要求1的技术方案已被对比文件1（CNxxxxxxA）公开，因此不具备新颖性。"

**分析要点**：
- 找出权利要求的技术特征
- 逐个特征与对比文件对比
- 关注：审查员是否将不同实施例拼凑对比（这是不允许的）

**判断依据**：
- 新颖性是**单一对比文件**原则
- 对比文件必须**单独**公开权利要求的**全部**技术特征
- 上、下位概念的区别（如"金属"vs"铜"）

### 二、创造性缺陷（专利法第22条第3款）

**审查员论述模式**：
> "权利要求1与对比文件1的区别在于[特征A]，但该区别已被对比文件2公开，且[特征A]在对比文件2中的作用与其在权利要求1中的作用相同，因此权利要求1不具备创造性。"

**分析要点**：
- 确定最接近的现有技术（D1）
- 确定区别技术特征和实际解决的技术问题
- 判断区别特征是否给出技术启示

**"三步法"审查**：
```
步骤1：确定最接近的现有技术
步骤2：确定区别技术特征 → 实际解决的技术问题
步骤3：判断要求保护的发明是否显而易见
```

**常见反驳切入点**：

| 切入点 | 说明 |
|-------|------|
| 区别特征未被公开 | D2没有公开审查员所说的区别特征 |
| 作用不同 | 区别特征在D2中的作用与在本发明中不同 |
| 无技术启示 | D2没有给出将其公开内容应用于D1的启示 |
| 结合障碍 | D1和D2存在技术矛盾，无法结合 |
| 预料不到的效果 | 本发明取得了D1和D2无法预期的技术效果 |

### 三、权利要求不清楚（专利法第26条第4款）

**审查员论述模式**：
> "权利要求1中的'适当'、'优选'等表述导致保护范围不确定。"

**分析要点**：
- 识别模糊表述（"大约"、"适当"、"优选"、"等等"）
- 判断是否确实导致保护范围不清楚

**常见应对**：
- 用具体数值范围替换模糊表述
- 删除不必要的限定词
- 从说明书中补充具体定义

### 四、权利要求得不到说明书支持（专利法第26条第4款）

**审查员论述模式**：
> "权利要求1概括过于宽泛，说明书仅公开了[具体实施方式]，无法支持权利要求所要求保护的范围。"

**分析要点**：
- 权利要求的概括范围是否超出说明书的教导
- 说明书中是否充分公开了权利要求的所有技术方案

### 五、缺少必要技术特征（实施细则第20条第2款）

**审查员论述模式**：
> "独立权利要求1缺少[特征X]，该特征是解决技术问题所必不可少的。"

### 六、其他常见意见

| 类型 | 说明 |
|------|------|
| 说明书修改超范围 | 修改内容超出了原申请文件记载的范围 |
| 重复授权 | 同样的发明创造已被授予专利权 |
| 不属于保护客体 | 智力活动的规则和方法、疾病诊断治疗方法等 |

## 对比文件分析要点

### 识别对比文件的关键信息

```python
FOR 每篇对比文件:
  提取 = {
    "文件编号": "D1/D2/...",
    "公开号": "CNxxxxxxA",
    "技术领域": "...",
    "要解决的技术问题": "...",
    "技术方案核心": "...",
    "具体实施方式": {
      "实施例1": "...",
      "实施例2": "..."
    },
    "审查员引用的具体段落": "..."
  }
END FOR
```

### 注意事项

1. **对比文件的公开日**必须在申请日之前
2. **同一对比文件的不同段落**可以用于新颖性判断
3. **不同对比文件的组合**只能用于创造性判断，不能用于新颖性判断
4. 注意审查员引用的段落是否确实公开了所声称的内容
