# 关键数字技术专利分类体系参考

本 Skill 提供国家知识产权局发布的《关键数字技术专利分类体系（2023年版）》的分类目录和关键词，用于优先审查匹配和专利分类定位。

---

## 分类体系总览

《关键数字技术专利分类体系（2023年版）》于2023年9月由国知局发布，采用**线分类法**将关键数字技术划分为3至5级技术分支，共计**7个技术领域、585个技术分支**。

```
关键数字技术（7大技术领域）
├── 1. 人工智能（44个分支）
│   ├── 1.1 人工智能硬件平台
│   ├── 1.2 人工智能通用技术
│   └── 1.3 人工智能关键技术
├── 2. 高端芯片（85个分支）
│   ├── 2.1 半导体设备
│   ├── 2.2 半导体材料
│   ├── 2.3 芯片制造
│   ├── 2.4 封装测试
│   └── 2.5 芯片设计
├── 3. 量子信息（42个分支）
│   ├── 3.1 量子测量
│   ├── 3.2 量子计算
│   └── 3.3 量子通信
├── 4. 物联网（70个分支）
│   ├── 4.1 感知
│   ├── 4.2 通信
│   ├── 4.3 计算
│   └── 4.4 安全
├── 5. 区块链（38个分支）
│   ├── 5.1 核心技术
│   └── 5.2 增强技术
├── 6. 工业互联网（112个分支）
│   ├── 6.1 网络层
│   ├── 6.2 平台层
│   └── 6.3 安全层
└── 7. 元宇宙（194个分支）
    ├── 7.1 沉浸式计算
    ├── 7.2 WEB 3.0
    └── 7.3 新型基础设施
```

详细的技术分支与关键词对照表见 [分类关键词表](references/classification-keywords.md)。

## 匹配方法

当用户请求匹配分类体系时，按以下步骤执行：

### 步骤 1：提取专利技术方案的核心技术特征

从用户提供的文档中提取：
- 核心技术方向
- 关键技术手段
- 应用领域/场景

### 步骤 2：逐级匹配

```
1. 匹配技术领域 → 确定属于 7大领域中的哪一个
2. 匹配一级技术分支 → 确定子方向
3. 匹配二级/三级技术分支 → 确定具体技术类别
4. 提取关键词 → 从对应技术分支的关键词列表中选择最匹配的
```

逐级匹配时，读取 `references/classification-keywords.md` 中对应技术领域的详细关键词表。

### 步骤 3：输出匹配结果

```markdown
## 分类匹配结果

- **技术领域**: [领域名称]
- **一级技术分支**: [分支名称]
- **二级技术分支**: [分支名称]
- **匹配关键词**: [关键词列表]
- **匹配理由**: [简要说明为什么匹配此分类]
- **优先审查建议**: [是否符合优先审查条件]
```
