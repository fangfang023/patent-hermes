## 二、修订标记版权利要求书示例

以下展示修订标记版在 Word 文档中的视觉效果。在 Markdown 中用 ~~删除线~~ 表示删除内容，用 <u>下划线</u> 表示新增内容。实际 Word 输出中两者均为红色字体。

### 修订标记示例

**权利要求1**（有修改——替换+新增）：

1. 一种智能文档分类方法，所述特征提取模块，~~用于对输入文档进行特征提取~~ <u>采用多尺度特征提取网络，所述多尺度特征提取网络包含至少三个不同尺度的卷积分支，各分支的卷积核尺寸分别为1×1、3×3和5×5，用于对输入文档进行多粒度特征提取</u>，所述分类模块根据提取的特征进行文档类型判定。

**权利要求2**（无修改）：

2. 根据权利要求1所述的方法，其特征在于，所述分类模块采用支持向量机或神经网络分类器。

**权利要求3（原）**（整条删除，已并入权1）：

~~3. 根据权利要求1所述的方法，其特征在于，所述特征提取模块采用多尺度特征提取网络，所述多尺度特征提取网络包含至少三个不同尺度的卷积分支，各分支的卷积核尺寸分别为1×1、3×3和5×5。~~

**权利要求3（新，原权4）**（有修改——引用关系变更）：

<u>3.</u> ~~根据权利要求3~~ <u>根据权利要求1</u> 所述的方法，其特征在于，所述动态权重分配机制根据文档类型自适应调整文本和图像特征的贡献比例。

**权利要求4（新编号权4，原权5）**（无修改）：

### 标记规则总结

| 修改类型 | Word 视觉效果 | Markdown 表示 | 说明 |
|---------|-------------|--------------|------|
| 替换 | ~~旧内容~~ → <u>新内容</u> | 删除紧跟插入 | 红色+删除线 紧跟 红色+下划线 |
| 新增 | <u>新增文字</u> | 下划线标记 | 红色+下划线 |
| 整条删除 | ~~整条内容~~ | 全段删除线 | 红色+删除线覆盖整段 |
| 编号调整 | ~~旧编号~~ <u>新编号</u> | 编号处删除线+下划线 | 标注旧编号和新编号 |
| 引用变更 | ~~旧引用~~ <u>新引用</u> | 引用处删除线+下划线 | 标注旧引用和新引用 |
| 无修改 | 正常黑色文本 | 无标记 | 无需任何特殊样式 |
