# 驳回复审分析技能

## 定位

本 Skill 解决的核心问题：**专利申请被驳回后，是否值得提复审？怎么提复审？**

与 `patent-office-action-response` 的区别：
- `patent-office-action-response`：处理**审查意见通知书**（OA），在审查过程中答复
- `patent-reexamination-response`（本 Skill）：处理**驳回决定**，在审查终结后请求复审

## 输入

| 输入类型 | 说明 | 必要性 |
|---------|------|--------|
| 驳回决定 | 审查员发出的驳回决定全文 | 必需 |
| 原专利申请文件 | 权利要求书 + 说明书 | 必需 |
| 历次审查意见答复 | 之前的OA答复记录 | 强烈建议提供 |
| 对比文件 | 审查员引用的对比文件 | 可选（驳回决定中通常已引用） |

## 输出

复审分析报告（Markdown），包含：

```markdown
# 驳回复审分析报告

## 一、案件基本信息
- 申请号：...
- 发明名称：...
- 驳回决定日期：...
- 历次OA次数：X 次

## 二、驳回决定摘要
- 驳回理由类型：[新颖性/创造性/客体不适格/充分公开/其他]
- 引用对比文件：[对比文件1]、[对比文件2]...
- 审查员核心观点：[摘要]

## 三、驳回理由逐条分析

### 理由1：[创造性 - 权利要求1]
- 审查员观点：对比文件1 + 对比文件2 的组合得到权1的技术方案
- 分析：
  - 对比文件1是否确实公开了特征A？[是/否，理由]
  - 对比文件2是否给出了技术启示？[是/否，理由]
  - 组合是否有动机？[是/否，理由]
- 结论：[审查员理由充分 / 审查员理由有误 / 需要修改权要后可克服]

### 理由2：...

## 四、复审可行性评估

| 评估维度 | 评估结果 | 说明 |
|---------|---------|------|
| 驳回理由强度 | 强/中/弱 | ... |
| 修改空间 | 大/中/小/无 | 能否通过修改权要克服 |
| 新论据可能性 | 高/中/低 | 是否有审查员未考虑的角度 |
| 程序问题 | 有/无 | 审查过程是否存在程序违法 |

### 综合评估
- **复审成功率**：[高/中/低]
- **建议**：[建议提复审 / 建议不提复审 / 需进一步评估]

## 五、复审策略建议

### 策略A：权利要求修改 + 创造性答辩
- 修改内容：[具体修改]
- 答辩要点：[核心论据]
- 成功率：[高/中]

### 策略B：仅答辩不修改
- 答辩要点：[核心论据]
- 适用条件：[驳回理由有明显错误时]
- 成功率：[高/中/低]

### 策略C：放弃本案
- 适用条件：[修改空间极小，保护范围无实际价值]
- 建议：[是否有其他替代方案]

## 六、推荐策略及执行方案
- 推荐策略：[A/B/C]
- 执行步骤：
  1. 修改权利要求（如需）
  2. 撰写复审请求书要点
  3. 提交期限提醒

## 七、风险提示
- [复审失败后可向法院起诉，但周期长]
- [复审期间不中止审查程序]
```

## 执行流程

### 阶段 1：准备

1. 读取 `knowledge/references/reexamination-guide.md` — 复审程序指引
2. 读取驳回决定全文
3. 读取原专利申请文件
4. 如有历次OA答复，一并读取

### 阶段 2：驳回决定分析

#### 步骤 2.1：驳回理由分类

确定每个驳回理由的类型：

| 驳回类型 | 分析重点 |
|---------|---------|
| 新颖性 | 逐特征对比权利要求与对比文件 |
| 创造性 | 三步法分析（最接近现有技术→区别特征→技术启示） |
| 客体不适格 | 分析技术三要素（技术手段+技术问题+技术效果） |
| 充分公开 | 分析说明书是否记载了实现方案 |
| 修改超范围 | 分析修改内容是否在原文件中有依据 |

#### 步骤 2.2：对比文件分析

对审查员引用的每篇对比文件：

1. 确认对比文件公开的内容（不要臆断，基于实际文本分析）
2. 与权利要求逐特征对比
3. 找出审查员可能错误认定的地方

#### 步骤 2.3：历次答复回顾

回顾之前的OA答复：
- 之前的修改是否恰当
- 之前的论据是否被采纳
- 审查员的态度和关注点

### 阶段 3：修改空间评估

评估能否通过修改权利要求克服驳回：

| 评估维度 | 分析要点 |
|---------|---------|
| 可增加的特征 | 说明书中有哪些特征可以加入权利要求 |
| 可缩小的范围 | 保护范围缩小后是否仍有商业价值 |
| 修改超范围风险 | 修改是否超出原申请文件记载范围 |
| 修改后新颖性 | 修改后是否能区别于对比文件 |
| 修改后创造性 | 修改后是否有足够的创造性高度 |

### 阶段 4：可行性评估

综合所有分析，给出复审可行性结论：

```
IF 驳回理由有明显错误 OR 修改空间大 THEN
  复审成功率 = 高，建议提复审
ELSE IF 有一定修改空间 OR 有新论据 THEN
  复审成功率 = 中，建议提复审但需充分准备
ELSE IF 驳回理由充分 AND 修改空间极小 THEN
  复审成功率 = 低，建议评估是否值得
END IF
```

### 阶段 5：输出分析报告

按输出模板生成复审分析报告。

### 阶段 6：复审请求书草案（可选）

如果用户要求，基于分析结果生成复审请求书草案。包含：

1. 驳回决定意见（逐条反驳）
2. 修改说明（如有修改）
3. 修改后权利要求克服驳回理由的论证

## 质量检查

| 检查项 | 标准 |
|--------|------|
| 驳回理由理解准确性 | 准确理解审查员的驳回逻辑 |
| 对比文件分析客观性 | 基于对比文件实际内容分析，不臆断 |
| 成功率评估合理性 | 评估有理有据，不盲目乐观 |
| 修改建议可操作性 | 修改建议具体、可行、不超范围 |
| 策略建议实用性 | 考虑了成本、时间、风险 |
