# 专利化方案重述

## 核心任务

生成或更新中文《专利化方案重述》。本技能处理的是“技术方案理解与专利化重述”，不是权利要求撰写、说明书撰写、权项布局建议、新颖性/创造性分析、侵权分析或保护范围评价。

全文必须使用以下信息来源标注：

- `【明示】`：技术交底书、参考材料、图示、会议记录、发明人补充说明或发明人确认反馈中明确记载的内容。
- `【保守推断】`：基于原始材料、上下文、技术逻辑或工程常识作出的克制推断；必须说明推断依据，不得写成确定事实。
- `【待确认】`：材料缺失、表达不清、存在冲突、存在多种解释、无法读取或会影响方案本质理解的内容。

## 执行模式

先判断当前属于哪一种模式：

1. 初次重述：用户提供技术交底书、发明人说明、图示、会议纪要、产品资料、测试数据或其他相关材料，并要求进行专利化方案重述、方案消化、技术方案整理或同类任务。
2. 续写：上一轮《专利化方案重述》以 `【未完待续：下一部分从“……”继续】` 结束。
3. 发明人确认后更新：用户提供针对上一版 `【待确认】` 事项的发明人确认反馈，并要求更新上一版重述。

## 初次重述流程

执行初次重述或续写时，必须读取并遵循 `references/restatement-prompt.md`。该文件是完整输出结构、信息来源分级、强制展开规则、表格规则、续写协议和禁止事项的控制性规范。

执行时应当：

1. 直接读取用户已经提供或上传的全部相关材料，不要求用户把全文重新粘贴进提示词。
2. 将多个文件或多段材料作为同一技术方案的资料集合综合理解，不孤立处理单个文件。
3. 对无法读取的附件、图片、表格、图示或关键材料，明确说明其未被纳入理解范围，并把由此造成的影响列为 `【待确认】`。
4. 围绕技术事实、技术问题、技术手段、特征关系、运行机制和技术效果展开，不把商业效果、管理效果、教学效果或用户体验直接写成技术效果。
5. 对业务化、产品化或口语化表述进行技术化还原，但不得脱离原始材料任意扩展。

如果单次输出无法完整呈现，不得压缩内容，不得删减章节，不得降低分析颗粒度；应在章节或小节边界停止，并以如下格式结尾：

```text
【未完待续：下一部分从“……”继续】
```

只有在全部章节完整输出后，才输出“最终理解成熟度结论”。

## 发明人确认后更新流程

当用户反馈发明人确认内容时，必须先读取 `references/confirmation-update-protocol.md`，再判断是否可以更新上一版。

更新前必须完成以下判断：

1. 找到上一版完整《专利化方案重述》。如用户指定了文件路径，以该文件为准；如存在多个版本，使用同一技术方案下最新的完整版本。
2. 提取上一版中的全部未解决事项，包括：
   - 章节 7.3 或同等表格中的所有待确认问题；
   - 各章节正文中的 `【待确认】` 标注；
   - 各表格中以 `【待确认】` 开头的单元格；
   - 最终理解成熟度结论中仍影响方案理解的不确定点。
3. 将用户本轮反馈逐项对应到每个待确认事项，判断其是否已经充分补齐。
4. 只要仍有任一事项未回答、仅部分回答、反馈含糊、存在新的冲突或不能确定是否来自发明人确认，就不得更新上一版。
5. 只有当全部待确认事项都被充分补齐后，才启动对上一版《专利化方案重述》的更新。

若反馈尚未补齐全部待确认事项，应即时回复：

- 暂不更新上一版《专利化方案重述》；
- 仍有哪些事项待与发明人确认；
- 为什么现有反馈不足以补齐这些事项。

此时不得输出更新版正文，也不得把部分确认内容先行改写进上一版。

## 全部补齐后的更新规则

当确认用户反馈已经补齐全部待确认事项后，输出完整更新版《专利化方案重述》，并遵守以下规则：

1. 将本轮反馈作为“发明人补充确认内容”纳入原始材料范围。
2. 对已由发明人明确确认的内容，重分类为 `【明示】`。
3. 修改所有受影响章节、表格、因果链、特征解释、技术效果说明和最终理解成熟度结论，不得只修改“待确认事项”表。
4. 更新版中不再保留已解决事项的 `【待确认】` 标签或“待与发明人确认”的提示。
5. 如果用户反馈引入新的实质矛盾或新的关键不确定点，应视为尚未全部补齐，不启动更新。
6. 除非用户明确要求差异对照或局部修改，否则输出完整更新版，而不是补丁式片段。

## 质量门控

输出前进行内部核对：

- 所有材料中出现的结构部件、模块、步骤、数据、参数、关系、问题、效果、推断和不确定点均已按要求展开；
- 提示词要求的表格均已实际填写，不留空，不使用 `同上`、破折号或占位语替代实质判断；
- 每个 `【保守推断】` 都说明了推断依据；
- 初次重述中所有影响方案理解的不确定点均标注为 `【待确认】`；
- 发明人确认后更新模式下，未补齐全部待确认事项前不启动更新；
- 输出中不包含权利要求、说明书正文、权项布局建议、保护范围评价、新颖性/创造性判断或侵权判断。
