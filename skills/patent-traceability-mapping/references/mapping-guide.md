# 溯源映射表字段规范与输出模板

## 一、映射表字段定义

### 核心字段

| 字段 | 说明 | 示例 |
|------|------|------|
| 权利要求 | 权利要求编号及引用关系 | 权1（独立）、权3（引用权2） |
| 技术特征 | 该权利要求中的关键技术特征描述 | "基于滑动窗口的流式数据处理引擎" |
| 交底书来源 | 交底书中对应的精确位置 | §2.1第3段 / 第2章"技术方案"第3段 |
| 说明书对应 | 说明书中对应的章节位置 | 发明内容§2.3 / 具体实施方式§4.1 |
| 实施例支撑 | 哪些实施例体现了该特征 | 实施例1、实施例3 |
| 置信度 | 匹配的可靠程度 | 精确匹配 / 语义等价 / 推断对应 / 未找到依据 |

### 置信度定义

| 级别 | 含义 | 说明 |
|------|------|------|
| **精确匹配** | 交底书原文与权利要求特征几乎一致 | 技术手段、参数、效果描述直接对应 |
| **语义等价** | 表述不同但技术实质相同 | 交底书用通俗语言，权利要求用专利语言 |
| **推断对应** | 需要逻辑推断才能关联 | 交底书描述了上下文，特征从中可推导 |
| **未找到依据** | 在交底书中找不到对应描述 | 需要补充交底书或调整权利要求 |

## 三、映射规则

### 交底书段落定位规则

1. 如果交底书有明确的章节编号（如 §2.1），直接使用
2. 如果交底书无编号，按"第N章第M段"格式标注（段落从该章节开头算起）
3. 如果一个特征跨越多个段落，标注范围（如 §2.1第3-5段）

### 说明书章节定位规则

1. 优先定位到最小子章节（如"具体实施方式 > 实施例1 > 步骤S203"）
2. 如果某特征在"发明内容"和"具体实施方式"中都有描述，两者都标注
3. 实施例编号使用说明书中实际使用的编号

### 置信度判定规则

1. **精确匹配**：技术特征的核心表述（动词+对象+方式）在交底书中能找到原文
2. **语义等价**：交底书描述的是同一技术手段，但用了不同的词汇或句式
3. **推断对应**：交底书中没有直接描述该特征，但描述了其上下文或前置条件
4. **未找到依据**：在交底书全文中搜索后，确实无法定位到相关描述
