# 信息收集

## 目标

充分理解用户输入的技术创新内容。

## 询问问题清单

如果用户输入信息不足，需要询问以下问题：

1. **发明名称**：发明的简明名称（25字以内）

2. **技术领域**：本发明属于哪个技术领域？

3. **背景技术**：
   - 现有技术方案是什么？
   - 现有方案存在的主要问题/缺陷？

4. **发明内容**：
   - 要解决什么技术问题？
   - 核心创新点有哪些？
   - 技术方案是什么？（具体说明实现方式）
   - 有益效果是什么？

5. **实施方式**：
   - 如何实施本发明？
   - 关键技术参数是什么？
   - 是否有具体实施例？

## 退出条件

当收集到足够信息以理解：
- 发明解决什么问题
- 发明如何解决问题（包括技术实现方式）
- 与现有方案的区别
- 关键技术特征及其实现
