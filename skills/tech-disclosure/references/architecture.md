# 整体架构构建与创新点关联性分析

## 目的

在生成创新点之前，必须先构建整体技术架构，确保创新点之间有明确的层次定位和依赖关系，避免创新点割裂。

---

## 步骤一：绘制技术架构图

用文字描述技术方案的分层架构（选择其一）：

### 方案A：四层架构（适用于数据处理类技术）

```
┌─────────────────────────────────────────┐
│         应用层 / 功能输出             │  ← 用户可见的功能和效果
├─────────────────────────────────────────┤
│         业务逻辑层 / 处理流程         │  ← 业务规则和流程控制
├─────────────────────────────────────────┤
│         核心算法层 / 技术实现         │  ← 算法、模型、核心计算
├─────────────────────────────────────────┤
│         数据层 / 存储与传输           │  ← 数据存储、传输、格式
└─────────────────────────────────────────┘
```

### 方案B：输入-处理-输出架构（适用于算法类技术）

```
┌──────────┐     ┌──────────────┐     ┌──────────┐
│  输入层   │────→│   处理层    │────→│  输出层   │
└──────────┘     └──────────────┘     └──────────┘
                 ↑         ↑
            ┌────┴─────┐   └─────┐
            │模块1    │模块2      │
            │(算法A)  │(算法B)    │
            └─────────┴───────────┘
```

### 方案C：分布式架构（适用于系统类技术）

```
┌──────────────┐     ┌──────────────┐     ┌──────────────┐
│   前端节点   │────→│   中间件     │────→│   后端服务   │
└──────────────┘     └──────────────┘     └──────────────┘
      ↑                   ↑                   ↑
   用户交互            消息队列           数据库
```

---

## 步骤二：识别核心创新点的层次定位

对每个创新点，说明：
1. 该创新点位于哪一层？（应用层/算法层/数据层/输入层/处理层/输出层等）
2. 它的上层依赖什么？
3. 它的下层支撑什么？

---

## 步骤三：分析创新点关联性（从专利代理师角度）

### 判断标准

从专利代理师角度判断创新点之间的必然联系：

| 判断维度 | 具体问题 | 分析结论 |
|---------|---------|---------|
| **技术依赖** | 创新点 A 是否依赖创新点 B 才能实现？ | 依赖/不依赖 |
| **问题关联** | 创新点 A 与创新点 B 是否服务于同一技术问题？ | 是/否 |

### 结论处理

- **存在必然联系**（满足以上任一维度）：纳入同一专利
- **关联度不足**（都不满足）：分析关联度，考虑拆分到不同专利

### 常见情况示例

| 情况 | 示例 | 处理建议 |
|-----|------|---------|
| 技术依赖 | 创新点B使用创新点A的输出作为输入 | 纳入同一专利 |
| 同一问题 | 两个创新点都是为了提高处理精度 | 纳入同一专利 |
| 独立模块 | 创新点A是前端界面优化，创新点B是后端算法 | 关联度需分析，可能拆分 |

---

## 步骤四：构建创新点关联表

基于架构定位和关联性分析，填写关联表：

```markdown
| 创新点 | 层次定位 | 依赖关系 | 协同作用 |
|-------|----------|----------|---------|
| 创新点一 | [具体层次] | - | 提供[什么能力] |
| 创新点二 | [具体层次] | 创新点一的输出 | 支撑[其他创新点]的功能 |
| 创新点三 | [具体层次] | 使用创新点一的结果 | 实现[什么效果] |
```

## 分析结论

创新点[编号]之间存在[技术依赖/协同/互补]关系，共同实现[整体技术目标]。

---

## ⚠️ 重要

只有完成此步骤，才能进入创新点详细撰写！
