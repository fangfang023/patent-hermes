# 驳回复审程序指引

## 1. 法律依据

### 《专利法》第四十一条

专利申请人对国务院专利行政部门驳回申请的决定不服的，可以自收到通知之日起三个月内，向专利复审委员会请求复审。

### 《专利法实施细则》第六十条

请求人在提出复审请求或者在对专利复审委员会的复审通知书做出答复时，可以修改专利申请文件；但是，修改应当仅限于消除驳回决定或者复审通知书指出的缺陷。

---

## 2. 复审流程

```
收到驳回决定
    │
    │ （3个月内）
    ▼
提交复审请求
    │
    ▼
形式审查（2-3个月）
    │
    ├── 形式不合格 → 补正通知书 → 补正
    │
    ▼
前置审查（由原审查部门审查）
    │
    ├── 原审查部门同意撤销驳回 → 结案（撤销驳回决定）
    │
    ├── 原审查部门坚持驳回 → 进入合议审查
    │
    ▼
合议审查
    │
    ├── 可能发出复审通知书（可答复）
    │
    ▼
复审决定
    ├── 撤销驳回决定 → 返回原审查部门继续审查
    └── 维持驳回决定 → 申请人收到决定后3个月内向法院起诉
```

---

## 3. 复审可行性分析要素

### 3.1 复审成功率评估维度

| 维度 | 评估要点 | 权重 |
|------|---------|------|
| **驳回理由强度** | 审查员引用的对比文件是否确实公开了相关技术特征 | 高 |
| **修改空间** | 能否通过修改权利要求克服驳回理由 | 高 |
| **新证据/新理由** | 是否有审查员未考虑的新论据或新对比文件 | 中 |
| **程序缺陷** | 审查过程是否存在程序违法 | 低 |
| **技术领域差异** | 审查员是否错误理解了技术领域或技术方案 | 中 |

### 3.2 驳回类型与复审策略

| 驳回类型 | 典型理由 | 复审策略 | 成功率 |
|---------|---------|---------|-------|
| **新颖性驳回** | 对比文件公开了全部技术特征 | 分析对比文件是否确实公开了所有特征；修改权要增加区别特征 | 中 |
| **创造性驳回** | 对比文件组合能得到技术方案 | 分析组合是否有技术启示；强调技术效果的不可预期性 | 中-高 |
| **客体不适格** | 不属于专利保护客体 | 重新界定技术方案，强调技术三要素（手段+问题+效果） | 低-中 |
| **充分公开驳回** | 说明书未充分公开 | 补充实验数据（视情况）；论证已充分公开 | 中 |
| **修改超范围** | 修改超出原申请文件记载范围 | 论证修改内容已在原文件中隐含或可直接推导 | 低 |

### 3.3 不建议提复审的情形

- 驳回理由充分，权利要求无法修改
- 修改空间极小，修改后保护范围无实际价值
- 技术方案本身属于明确排除的客体
- 审查过程无程序问题，事实认定正确

## 4. 复审请求书撰写要点

### 4.1 结构

```
复审请求书
├── 一、基本信息
│   ├── 申请号、发明名称
│   ├── 驳回决定文号、日期
│   └── 请求人信息
│
├── 二、对驳回决定的意见
│   ├── 驳回决定摘要
│   ├── 逐条分析驳回理由的错误
│   └── 每条分析应包含：事实→法律→结论
│
├── 三、修改说明（如修改了权利要求）
│   ├── 修改内容对照
│   ├── 修改依据（原说明书/权利要求书的出处）
│   └── 修改后的方案如何克服驳回理由
│
└── 四、结论
    └── 请求撤销驳回决定
```

### 4.2 论述策略

**创造性答辩（最常见）**

1. **确定最接近的现有技术**：承认对比文件1是最接近的，或论证另一个对比文件更接近
2. **确定区别技术特征**：逐字对比，找出权利要求与对比文件1的实际区别
3. **确定实际解决的技术问题**：基于区别特征重新定义技术问题
4. **论证无技术启示**：
   - 对比文件2没有给出将区别特征应用到对比文件1的启示
   - 对比文件2解决的技术问题与本申请不同
   - 本申请获得了预料不到的技术效果

**新颖性答辩**

1. 逐特征对比：将权利要求的每个技术特征与对比文件逐一对比
2. 指出未公开的特征：明确指出哪些特征在对比文件中没有记载
3. 反驳"隐含公开"：如果审查员认为某特征是"隐含公开"，论证为何不是

### 4.3 注意事项

- 复审请求书应在收到驳回决定后3个月内提交
- 可以同时修改权利要求，但修改仅限于消除驳回理由指出的缺陷
- 复审期间仍可修改权利要求
- 复审成功后，案件返回原审查部门继续审查，有可能再次收到审查意见

## 5. 复审与后续程序的关系

```
驳回决定 → 复审请求 → 复审决定
                          │
                          ├── 撤销驳回 → 返回审查 → 可能再次OA → 授权/再次驳回
                          │
                          └── 维持驳回 → 法院起诉（3个月内）
                                            │
                                            └── 北京知识产权法院
                                                  │
                                                  └── 不服 → 高级人民法院
```

## 6. 复审费用和时间

| 项目 | 内容 |
|------|------|
| 复审请求费 | 发明专利：1000元 |
| 提交期限 | 收到驳回决定之日起3个月 |
| 前置审查期 | 约2-3个月 |
| 合议审查期 | 约6-12个月 |
| 总周期 | 约8-18个月 |
