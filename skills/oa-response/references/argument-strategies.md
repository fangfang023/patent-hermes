## 一、新颖性缺陷（专利法第22条第2款）

**论证目标**：找出申请与对比文件的区别技术特征，证明未被单独一篇对比文件完全公开。

**论证框架**：

```markdown
**申请人意见**：

审查员引用对比文件1（CNxxxxxxA）认为权利要求1不具备新颖性，申请人对此不能认同。

权利要求1的技术方案与对比文件1公开的内容存在以下区别：

| 技术特征 | 权利要求1 | 对比文件1 |
|---------|----------|----------|
| 特征A | [具体内容] | [对比文件公开的内容或"未公开"] |
| 特征B | [具体内容] | [对比文件公开的内容或"未公开"] |

具体而言，对比文件1第[X]段仅公开了[具体内容]，并未公开权利要求1中的[区别特征]。因此，权利要求1相对于对比文件1具备新颖性。
```

**核心要点**：
- 新颖性采用**单一对比文件**原则，不允许组合多篇
- 只需证明有一个技术特征未被公开即可

## 二、创造性缺陷（专利法第22条第3款）

**论证目标**：通过三步法反驳，论证区别特征非显而易见。

**论证框架（三步法反驳）**：

```markdown
**申请人意见**：

审查员认为权利要求1相对于D1结合D2不具备创造性，申请人对此不能认同。

**（1）区别技术特征的确定**

权利要求1与最接近现有技术D1的区别技术特征为：[具体区别]。

基于上述区别技术特征，权利要求1实际解决的技术问题是：[技术问题]。

**（2）技术启示的分析**

审查员引用D2认为其给出了将上述区别特征应用于D1的技术启示。然而：

- D2的技术领域为[领域]，其要解决的技术问题是[问题]，与本发明[相同/不同]；
- 区别特征在D2中的作用为[作用]，而在权利要求1中的作用为[不同作用]，两者作用不同；
- D2并未给出将其[特征]应用于D1以解决[技术问题]的任何启示。

**（3）预料不到的技术效果**

权利要求1的技术方案还取得了预料不到的技术效果：[具体效果，引用说明书数据]。

综上，权利要求1对于本领域技术人员而言并非显而易见，具备突出的实质性特点和显著的进步，符合专利法第22条第3款关于创造性的规定。
```

**反驳切入点选择**：详见 `oa-analysis-guide.md` 中"创造性缺陷"章节的"常见反驳切入点"表格，根据案件实际情况选取。

## 三、权利要求不清楚（专利法第26条第4款）

**论证目标**：澄清表述或修改后证明保护范围明确。

**论证框架**：

```markdown
**申请人意见**：

申请人已将权利要求1中的"[模糊表述]"修改为"[具体表述]"。

修改后的权利要求1的保护范围明确，所属技术领域的技术人员能够清楚地确定其含义。
```

**常见应对**：
- 用具体数值范围替换模糊表述（"适当" → "0.01-0.1"）
- 删除不必要的限定词（"优选"、"大约"）
- 从说明书中补充具体定义

## 四、权利要求得不到说明书支持（专利法第26条第4款）

**论证目标**：引用说明书段落证明权利要求可得到支持。

**论证框架**：

```markdown
**申请人意见**：

说明书第[X]段已充分公开了[具体内容]，权利要求1的技术方案能够得到说明书的支持。

具体而言，[引用说明书的实施例或具体描述]，所属技术领域的技术人员根据说明书的教导，能够实现权利要求1所要求保护的技术方案。
```

## 五、已修改权利要求的综合论证

**适用场景**：修改了权利要求后，需同时论证修改不超范围和修改后的可专利性。

**论证框架**：

```markdown
**申请人意见**：

申请人已对权利要求1进行了修改，将原从属权利要求X的附加技术特征并入独立权利要求。

**修改不超范围**：该修改依据来源于原说明书第[X]段和原权利要求X，属于原申请文件记载的范围。

**修改后的可专利性**：修改后的权利要求1进一步限定了[特征]，该特征在对比文件1和对比文件2中均未被公开。[继续按新颖性或创造性框架论证]。

因此，修改后的权利要求1具备新颖性和创造性。
```

## 语言规范

| 避免 | 应该 |
|------|------|
| "审查员理解有误" | "申请人对审查意见的理解有所不同" |
| "这是错误的" | "申请人认为该观点值得商榷" |
| "明显不同" | "存在以下具体区别..." |
| 情绪化表述 | 基于技术事实的客观论述 |

## 论证力度要求

- **新颖性**：只需证明有一个技术特征未被单独一篇对比文件公开即可
- **创造性**：需要更充分的论证，包括区别特征、技术启示、技术效果三个层面
- **已修改的权利要求**：需要同时论证修改不超范围和修改后具备可专利性
