# 批量专利生成工作流

## 工作流概述

本工作流描述如何从用户创意批量生成完整的专利文档体系，包括三篇完整论文、多个创意、每个创意的专利文件以及四种配套方案。

## 详细步骤说明

### 阶段 1：生成三种完整论文

**目标**：从工程、科技、经济三个维度对用户创意进行学术化分析，生成完整学术论文

| 文档类型 | 对应 Skill | 核心内容 | 输出位置 |
|---------|-----------|---------|---------|
| 工程论文 | `paper-engineering-paper` | 系统架构、可扩展性、高可用设计 | `工程论文_[timestamp].md` |
| 科技论文 | `paper-science-paper` | 技术新颖性、核心算法/框架、实验设计 | `科技论文_[timestamp].md` |
| 经济论文 | `paper-economy-paper` | 市场分析、商业模式、经济效益分析 | `经济论文_[timestamp].md` |

**关键点**：
- 三篇论文相互独立，可并行生成
- 每篇论文应包含该领域的完整学术结构
- 为后续创意挖掘提供多维度素材

---

### 阶段 2：创意挖掘

**目标**：从三篇完整论文中挖掘 3-5 个具体、可实施、具有商业价值的创意

**输入**：
- 工程论文（完整）
- 科技论文（完整）
- 经济论文（完整）

**输出**：
- 创意清单（包含 3-5 个创意）
- 每个创意包含：标题、技术方向、创新点、商业价值

**创意挖掘原则**：
1. **具体性**：创意必须具体可实施，不是泛泛而谈的概念
2. **创新性**：每个创意应有明确的技术创新点
3. **可专利性**：创意应具备申请专利的可能性
4. **商业价值**：每个创意应有清晰的商业价值定位
5. **差异性**：多个创意之间应有明确区分，避免重复

**示例创意结构**：

```markdown
## 创意 1: 智能垃圾分类系统

**技术方向**：
基于深度学习的图像识别技术，实现自动垃圾分类

**核心创新点**：
- 轻量化神经网络模型，适配边缘设备
- 多模态融合识别（图像+重量+材质）
- 自适应学习机制，持续优化识别准确率

**商业价值**：
- 降低人力成本，提高分类效率
- 适用于社区、商场、办公场所等多种场景
- 可与智慧城市系统集成
```

### 阶段 3：批量专利生成

**目标**：为每个创意生成专利文件（技术交底书）

**输入**：
- 创意列表（来自阶段 2）

**输出**：
- 每个创意对应一个专利文件（技术交底书）

| 文档类型 | 对应 Skill | 核心内容 | 输出位置 |
|---------|-----------|---------|---------|
| 专利（技术交底书） | `patent-tech-disclosure` | 技术背景、发明内容、具体实施方式、有益效果 | `创意[N]_[简述]_专利/专利_[timestamp].md` |

---

### 阶段 4：批量方案生成

**目标**：为每个创意基于专利文件生成四种配套方案

**输入**：
- 创意列表（来自阶段 2）
- 每个创意的专利文件（来自阶段 3）

**输出**：
- 每个创意生成 4 种配套方案

## 质量控制点

| 阶段 | 质量检查点 | 通过标准 |
|-----|-----------|---------|
| 阶段 1 | 论文完整性 | 三篇论文均生成，内容完整 |
| 阶段 2 | 创意数量与质量 | 3-5 个创意，每个创意具体可实施 |
| 阶段 3 | 专利生成成功率 | 所有专利文件成功生成，无遗漏 |
| 阶段 4 | 方案生成成功率 | 所有配套方案成功生成，无遗漏 |

## 触发示例

### 示例 1：完整批量生成

```
用户: "我有一个关于智能垃圾分类的想法，帮我批量生成所有相关的专利和配套方案"

执行: batch-patent-generator agent
输入: 智能垃圾分类创意
输出:
  - 3 篇完整论文
  - 创意清单（3-5 个创意）
  - 每个创意的专利文件
  - 每个创意的 4 种配套方案
```

### 示例 2：自动批量生成

```
用户: "根据这个创意，自动生成所有文档"

执行: batch-patent-generator agent
输入: 创意内容
输出: 同上
```

## 与其他 Agent 的区别

| Agent | 用途 | 触发场景 |
|-------|------|---------|
| `batch-patent-generator` | 批量生成完整专利文档体系 | 用户需要从创意批量生成多组文档 |
| `generate-docs-agent` | 单次文档生成 | 用户生成特定类型文档（技术方案、交底书等） |
| `document-reviewer-agent` | 文档质量审核 | 文档生成后的质量评审 |

---

## 注意事项

1. **执行时间**：批量生成需要较长时间，建议非高峰期执行
2. **存储空间**：确保有足够的磁盘空间存储生成的文档
3. **网络依赖**：部分文档生成可能需要联网检索信息
4. **人工审核**：生成的文档建议进行人工审核后再正式使用
5. **顺序依赖**：
   - 阶段 4（方案生成）依赖于阶段 3（专利生成）
   - 产品方案和运营方案需要读取专利文件内容作为输入
