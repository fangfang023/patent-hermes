# 来源定位与2026覆盖规则

本文件用于定位规则依据，并判断2026年修改是否覆盖2023年指南中的相应规则。

## 1. 规则依据范围

- 本技能依据《专利审查指南（2023）》及2026年修改对照内容整理，作为成稿规范检查的自包含规则摘要使用。
- 使用本技能时，不要求当前工作区存在指南PDF、修改对照表PDF或任何抽取文本目录。
- 如用户要求逐字核对、引用原文或处理本技能未覆盖的新修改，应以用户提供的官方文本或国家知识产权局公布的现行官方版本为准。

## 2. 撰写审查来源定位

- 申请文件形式: 指南2023第一部分第一章第4.2-4.5节；第五部分第一章第3节、第5节。
- 说明书、附图、权利要求、摘要初步审查: 指南2023第一部分第一章第4.2-4.5节；第一部分第二章第7.2-7.5节。
- 实用新型客体和文件要求: 指南2023第一部分第二章第6-7节。
- 不授予专利权客体: 指南2023第二部分第一章；修改2026涉及动物和植物品种、生物技术客体、AI/数据合规示例。
- 客体风险详细检查: `references/subject-matter-rules.md`。
- 说明书和权利要求书通用规则: 指南2023第二部分第二章第1-3节。
- 新颖性中特殊产品权利要求: 指南2023第二部分第三章第3.2.5节。
- 新颖性、创造性、实用性初步检查: `references/patentability-rules.md`。
- 创造性贡献必须写入权利要求、非贡献特征通常不产生创造性: 修改2026第二部分第四章第6.4节。
- 实用性和可再现性: 指南2023第二部分第五章，生物领域另见第二部分第十章第9.4.3节。
- 单一性: 指南2023第二部分第六章；化学单一性见第二部分第十章第8节。
- 修改不得超范围: 指南2023第二部分第八章第5.2节；实用新型初步审查见第一部分第二章第8节。
- 计算机程序: 指南2023第二部分第九章第1-5节。
- AI、大数据、算法特征、商业规则: 指南2023第二部分第九章第6节；修改2026第二部分第九章第6节。
- 比特流: 修改2026第二部分第九章新增第7节。
- 化学领域: 指南2023第二部分第十章第2-9节。
- 生物技术: 指南2023第二部分第十章第9节；修改2026第二部分第十章第9.1.2.3、9.1.2.4节。
- 中药领域: 指南2023第二部分第十一章。
- PCT进入国家阶段译文、附图、序列表和摘要: 指南2023第三部分第一章第3.2节、第三部分第二章相关内容。仅在任务涉及PCT文本时使用。
- 无效程序中权利要求修改: 指南2023第四部分第三章第4.6节；修改2026第四部分第三章第4.6.4节。仅在任务涉及无效修改文本时使用。

## 3. 与撰写审查相关的2026修改

以下内容作为当前覆盖规则适用：

- 发明人信息: 请求书不得填写单位、集体或人工智能名称；2026增加不得填写虚假发明人、一般不审查但有证据除外、发明人应为自然人并填写真实身份信息。该项通常属于形式事项，不属于权利要求/说明书实质撰写规则。
- 创造性评价: 评价对象是权利要求限定的技术方案整体。对现有技术作出贡献的技术特征应写入权利要求；未写入权利要求的，即使说明书有记载，创造性评价通常不考虑。对技术问题解决没有贡献的特征，即使写入权利要求，通常也不会对创造性产生影响。
- AI/大数据标题和范围: 2026将相关章节明确扩展为"涉及人工智能、大数据等包含算法特征或商业规则和方法特征"。
- AI/算法审查基准: 必要时应针对说明书内容审查；权利要求整体分析仍适用。
- AI/数据合规: 2026新增包含数据采集、标签管理、规则设置、推荐决策等违反法律、社会公德或公共利益时不得授权的规则和示例。
- AI说明书撰写: 2026新增或强化模型构建/训练应记载必要模块、层级或连接关系，训练必要步骤和参数；应用AI模型或算法应记载与具体领域/场景结合方式，以及输入/输出数据设置和内在关联关系。
- AI公开充分示例: 空间变换网络例说明，只要模型层级、输入/输出及关系清楚，且公知模型可由本领域技术人员构建，可以满足充分公开；癌症预测例说明，关键指标、因果/关联关系、验证数据不足会导致公开不充分。
- 比特流: 2026新增比特流客体与撰写规则。单纯比特流或仅由比特流语法元素限定的生成方法属于智力活动规则和方法风险；可围绕特定视频编码方法派生存储、传输和存储介质权利要求。
- 生物技术植物边界: 2026细化植物品种、野生植物、人工选育/改良植物及其繁殖材料、转基因动植物的客体判断。
- 序列表费用: 修改2026明确符合规定格式提交的计算机可读形式序列表不计算说明书附加费页数。该项属于费用/形式事项，不属于实质撰写规则。
- 无效程序修改文本: 修改2026要求专利权人修改权利要求书时提交全文替换页和修改对照表。仅在无效程序阶段任务中使用。

## 4. 审查输出模板

检查文本时，优先采用以下简洁结构：

```markdown
**结论**
一句话说明总体风险等级和最主要问题。

**明确缺陷**
- [对象] 问题。依据：指南2023/修改2026 + 部分/章/节。修改方向：...

**高风险**
- [对象] 风险。依据：...。需要补充/修改：...

**可优化**
- [对象] 建议。理由：...

**需补充确认**
- 材料中未直接记载...，需要确认...
```

如果某一类别没有问题，不必强行保留该标题。

## 5. 触发边界

- 仅当用户提供已经写好的权利要求书、说明书、摘要、附图说明或申请文件全文，并明确要求检查、审查、评价、质检、找缺陷、找风险或核对规范时使用本技能。
- 用户要求“撰写”“起草”“生成”“扩写”“改写”“完善”“布局”“提炼发明点”“组织权利要求”“补实施例”时，不使用本技能。
- 若同一任务同时包含撰写和检查，应先完成撰写任务；只有当用户明确要求对已经形成的文本进行规范性检查时，再使用本技能。
