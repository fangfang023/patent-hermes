# 专利法关键条款速查

本文档提供专利法及审查指南中与日常工作最相关的条款速查。

## 新颖性判断（第22条第2款）

### 判断标准
- 现有技术 = 申请日以前在国内外为公众所知的技术
- 抵触申请 = 同样的发明在申请日以前已由他人向专利局提出申请并记载在公告中

### 不丧失新颖性的宽限期（第24条）
- 在中国政府主办或承认的国际展览会上首次展出（6个月内）
- 在规定的学术会议或技术会议上首次发表（6个月内）
- 他人未经申请人同意而泄露（6个月内）

## 创造性判断（第22条第3款）

### 判断方法：三步法

```
步骤1：确定最接近的现有技术
步骤2：确定区别技术特征和发明实际解决的技术问题
步骤3：判断要求保护的发明是否显而易见
```

### 创造性判断要素

| 要素 | 说明 |
|------|------|
| 技术特征组合 | 非显而易见的技术特征组合可具有创造性 |
| 技术效果 | 取得了预料不到的技术效果 → 有创造性 |
| 克服技术偏见 | 突破本领域技术人员的技术偏见 → 有创造性 |
| 商业成功 | 如由技术特征直接导致 → 可作为创造性佐证 |

## 权利要求撰写规范速查

### 独立权利要求结构

```
一种[主题名称]，其特征在于，包括：
  [必要技术特征A]；
  [必要技术特征B]；
  [必要技术特征C]。
```

### 从属权利要求结构

```
根据权利要求[N]所述的[主题名称]，其特征在于，[附加技术特征]。
```
