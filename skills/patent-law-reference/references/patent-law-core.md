## 一、单一性判断（专利法第31条）

### 法律条文

> 一件发明或者实用新型专利申请应当限于一项发明或者实用新型。属于一个总的发明构思的两项以上的发明或者实用新型，可以作为一件申请提出。

### 审查指南判断标准（第二部分第二章 2.2.1）

**单一性判断方法：中间要素法**

1. 从多项发明中找出共同的"特定技术特征"
2. 特定技术特征 = 对现有技术做出贡献的技术特征
3. 多项发明之间通过该特定技术特征在技术上相互关联

**判断步骤**：
```
步骤1：确定各项发明的核心技术特征
步骤2：找出各项发明之间共同的技术特征
步骤3：判断共同特征是否对现有技术做出贡献（即是否是"特定技术特征"）
  → 是：满足单一性
  → 否：不满足单一性
```

### 常见单一性问题

| 情况 | 单一性判断 |
|------|-----------|
| 方法权利要求 + 实施该方法的装置权利要求 | 通常满足（方法+装置属于同一发明构思） |
| 独立方法权要 + 独立产品权要（无共同技术特征） | 通常不满足 |
| 多组权要保护同一方法的不同执行主体 | 通常满足（共享核心技术方案） |
| 母案与分案保护不同技术方向 | 需判断是否共享"特定技术特征" |

## 二、分案申请（实施细则第48-49条）

### 分案条件

| 条件 | 说明 |
|------|------|
| 提出时机 | 收到专利局发出的授予专利权通知书之日起两个月内，或在审查、复审、无效程序中 |
| 前提 | 原申请包含两项以上发明/实用新型 |
| 内容限制 | 分案申请的内容不得超出原申请记载的范围 |
| 独立性 | 分案申请享有原申请的申请日 |

### 分案策略要点

1. **分案时机**：通常在收到第一次审查意见通知书后，审查员指出单一性问题时提出
2. **分案数量**：原申请包含几组发明即可分出几个分案，无硬性上限
3. **保护范围**：分案的权利要求应与母案及兄弟分案的保护范围不重叠
4. **说明书共享**：分案可引用母案的说明书内容

## 三、优先审查（《专利优先审查管理办法》2017年）

### 优先审查条件

可请求优先审查的情形（依据《专利优先审查管理办法》第2条）：
1. 涉及节能环保、新一代信息技术、生物、高端装备制造、新能源、新材料、新能源汽车、智能制造等国家重点发展产业
2. 涉及省级以上人民政府鼓励的产业
3. 对国家利益或者公共利益具有重大意义
4. 其他需要优先审查的情形（如PCT国际申请进入中国国家阶段等）

### 优先审查流程

```
提交优先审查请求书 + 相关证明文件
  ↓
专利局审查是否符合条件的主题
  ↓
同意 → 审查周期缩短至约1年内
不同意 → 按普通程序审查
```

### 优先审查所需材料
- 优先审查请求书
- 相关证明文件（如：属于重点发展产业的说明、政府鼓励文件等）

## 四、权利要求撰写法定要求

### 独立权利要求

1. **两部分结构**：
   - 前序部分：主题名称 + 与现有技术共有的必要技术特征
   - 特征部分："其特征在于" + 区别于现有技术的必要技术特征

2. **必要技术特征判断**：
   - 删掉该特征后，发明还能否解决核心技术问题？
   - 能 → 非必要，应放入从属权利要求
   - 不能 → 必要，保留在独立权利要求中

3. **保护范围原则**：
   - 独立权利要求保护范围最宽
   - 用上位概念替代具体实施方式
   - 具体实施方式放入从属权利要求

### 从属权利要求

1. 必须包含引用部分和限定部分
2. 只能引用在前的权利要求
3. 引用两项以上权利要求时，必须是择一引用
4. 附加技术特征是对被引用权利要求的进一步限定

### 主题名称匹配

| 独立权利要求类型 | 对应从属权利要求主题 |
|----------------|-------------------|
| 一种方法 | 所述方法 |
| 一种装置/系统 | 所述装置/系统 |
| 一种存储介质 | 所述存储介质 |

## 五、说明书法定要求（实施细则第20条）

### 说明书必须按顺序包含的部分

1. **技术领域**：发明直接所属的技术领域
2. **背景技术**：对理解发明有帮助的现有技术，客观指出其缺陷
3. **发明内容**：
   - 技术问题（要解决什么）
   - 技术方案（怎么解决）
   - 有益效果（解决后带来什么好处）
4. **附图说明**：各附图的简要说明
5. **具体实施方式**：至少一个实施例，充分公开发明

### 说明书撰写要求

- 充分公开：使所属技术领域的技术人员能够实现
- 支持权利要求：保护范围不超出说明书公开内容
- 用词规范：无商业宣传用语，不使用"大约""左右"等模糊词
- 具体实施例：必须与权利要求对应，体现所有必要技术特征

## 六、审查意见答复要点

### 修改权利要求的限制（专利法第33条）

> 申请人可以对其专利申请文件进行修改，但是对发明和实用新型专利申请文件的修改不得超出原说明书和权利要求书记载的范围。

### 常见修改方式

| 修改类型 | 是否允许 | 条件 |
|---------|---------|------|
| 缩小独立权利要求保护范围 | 允许 | 增加的内容在原申请中有记载 |
| 增加从属权利要求 | 允许 | 基于说明书中记载的技术特征 |
| 删除权利要求 | 允许 | — |
| 扩大保护范围 | 禁止 | — |
| 改变发明主题 | 通常禁止 | 除非不超范围且未改变发明 |
| 将说明书中内容加入权利要求 | 允许 | 必须在原申请中有记载 |

### 答复期限

- 第一次审查意见：4个月
- 第二次及以后：2个月
- 可申请延期（最多2次，每次2个月）

## 七、驳回与复审

### 驳回条件

审查员在以下情形可以驳回：
1. 发明不符合专利法第2条第2款（不是发明）
2. 不符合第22条（缺乏新颖性、创造性、实用性）
3. 不符合第26条第3、4款（公开不充分、权利要求得不到支持）
4. 不符合第31条（缺乏单一性）
5. 修改超出原申请范围（第33条）

### 复审

- 收到驳回决定后3个月内向国务院专利行政部门提出复审请求
- 复审请求需附具理由和证据
- 可修改申请文件（但不得扩大保护范围）
- 对复审决定不服可向法院起诉
