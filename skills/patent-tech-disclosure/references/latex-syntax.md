# LaTeX 格式规范

## 目的

确保技术交底书中的数学公式使用标准 LaTeX 格式，保证文档质量和可转换性。

---

## 格式对照表

| 数学元素 | ❌ Unicode 文本 | ✅ LaTeX 格式 |
|---------|--------------|-------------|
| 上标 | `x^2`, `^(256×128)` | `$x^2$`, `$^{256 \times 128}$` |
| 下标 | `W_MT`, `x_i` | `$W_{MT}$`, `$x_i$` |
| 希腊字母 | `α, β, σ, π` | `$\alpha, \beta, \sigma, \pi$` |
| 集合符号 | `∈ R` | `$\in \mathbb{R}$` |
| 分数 | `a/b`, `1/2` | `$\frac{a}{b}$`, `$\frac{1}{2}$` |
| 根号 | `√x`, `√(a+b)` | `$\sqrt{x}$`, `$\sqrt{a+b}$` |
| 求和 | `Σ`, `Σ(i=1 to n)` | `$\sum_{i=1}^{n}$` |
| 积分 | `∫`, `∫f(x)dx` | `$\int_{a}^{b}$` |
| 矩阵 | `[a b; c d]` | `$\begin{pmatrix} a & b \\ c & d \end{pmatrix}$` |
| 点乘 | `W·M` | `$W \cdot M$` |
| 趋势 | `→` | `$\to$` 或 `$\rightarrow$` |

---

## 特殊场景规则

### 简单上标下标（仅限非常基础的情况）

允许：`²`, `³`, `¹`（仅单个数字上标）

禁止：`^(256)`, `_(MT)`, `x^(2n)`（复杂情况必须用 LaTeX）

### 内联公式 vs 块级公式

内联（嵌入行中）：用单个 `$...$`
- 示例：`设 $f(x) = x^2 + 1$，则...`

块级（独立段落）：用双 `$$...$$`
- ```markdown
  $$f(x) = \sum_{i=0}^{n} a_i x^i$$
  ```

### 文字与公式混排

- ❌ 错误：`其中 W_MT ∈ R^(256×128)`
- ✅ 正确：`其中 $W_{MT} \in \mathbb{R}^{256 \times 128}$`
- 使用 `\text{}` 在公式中插入中文：`$f(x) \text{ 其中 } x > 0$`

## DOCX 转换要求

当转换为 Word 文档时，**必须使用 `--mathml` 参数**：

```bash
pandoc input.md -o output.docx --mathml
```

此参数将 LaTeX 公式转换为 OMML（Office Math Markup Language）格式，使 Word 能够正确渲染可编辑的数学公式。
