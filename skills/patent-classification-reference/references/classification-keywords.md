# 关键数字技术专利分类体系（2023）— 技术分支与关键词对照表

> 来源：国家知识产权局《关键数字技术专利分类体系（2023年版）》（2023年9月发布）
> 官方PDF：https://www.cnipa.gov.cn/attach/0/d32119ae1faa4fbf9e308824862f87dd.pdf

本分类体系重点选取**人工智能、高端芯片、量子信息、物联网、区块链、工业互联网和元宇宙**等七类关键数字技术，采用线分类法划分为3至5级技术分支，共计**585个技术分支**。
