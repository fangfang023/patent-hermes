# 美标专利评审报告模板

本文件定义评审报告的输出结构、格式规范和各章节内容要求。

## 报告整体结构

```
1. 概述
2. 适格性评审（§101）
3. 新颖性评审（§102）
4. 非显而易见性评审（§103）
5. 充分公开与确定性评审（§112）
6. PCT 国际路径建议
7. 综合评审结论
8. 修改建议（按优先级）
```

---

## 风险等级定义

| 标记 | 等级 | 含义 | 对应操作 |
|------|------|------|---------|
| 🟢 | 低风险 | 预计可通过审查，无需修改或仅需微调 | 记录关注点，正常推进 |
| 🟡 | 中风险 | 需要修改权利要求或说明书，但不影响核心发明 | 按修改建议调整后可推进 |
| 🔴 | 高风险 | 可能被驳回，需重构权利要求或补充核心技术内容 | 优先处理，可能需要重新评估申请策略 |
